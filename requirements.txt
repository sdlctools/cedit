# The parsing stack is PINNED EXACTLY, and that is not fussiness.
#
# Every hash in `.cedit/` state (base doc hashes, overlay keys, conflict
# keys) is taken over `cedit/mdcore/utils.make_parser`, which is these
# packages in one configuration. A minor upgrade can change what the parser
# emits, which silently moves every hash and turns the next sync into a
# wall of false conflicts.
#
# The rest of the suite cannot see that happen — it computes both sides of
# every comparison with whatever parser it is running under. So upgrade
# deliberately, one pin at a time, and run the drift check:
#
#     venv/bin/python3 tests/parser_contract.py
#
# See .claude/rules/hash-stability.md before accepting any move it reports.
